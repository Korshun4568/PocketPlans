# Ручная приёмка

| Проверка | Ожидаемый результат |
|---|---|
| Первая загрузка с сетью | Loading, затем список; открывается правильная карточка |
| Первая загрузка без сети | Error и кнопка «Повторить» |
| Вернуть сеть, нажать «Повторить» | Новый запрос и список |
| Поиск заведомо отсутствующего текста | Empty, не пустой Success |
| Избранное + категория + запрос | Условия применяются совместно |
| Сортировка по цене | Каталог обновляется без ручного сетевого запроса |
| Создать два списка с разным бюджетом | Два отдельных плана |
| Добавить товар дважды в один список | Одна строка, количество 2 |
| Увеличить количество / отметить купленное | Общая и оставшаяся суммы пересчитываются |
| Превысить бюджет | Видна величина превышения |
| Удалить один список | Его строки удалены, второй список и каталог сохранены |
| Сохранить заметку, цель и избранное | Раздел «Моё» отражает решение и достижение цели |
| Очистить заметку/цель, снять избранное, сохранить | Товар исчезает из «Моё», каталог остаётся |
| Несколько обновлений с неизменной ценой | Нет повторных точек истории цены |
| Сохранить и применить фильтр после перезапуска | Восстанавливаются запрос, категория, избранное |
| Переименовать/удалить пресет | Изменения сохраняются |
| Открыть карточку дважды | В истории одна запись с последним временем |
| Очистить историю | Удаляются посещения, не каталог |
| Изменить тему, TTL, фон и перезапустить | Настройки остаются |
| Подготовить офлайн при выключенной периодике | Явная задача всё равно выполняется |
| Подготовить офлайн без сети, потом вернуть сеть | Задача ждёт сеть, затем выполняется по решению Android |
| После загрузки перезапустить без сети | Карточки, личные решения, списки и фильтры работают |
| Обновить без сети при наличии кэша | Ошибка видна, кэш и личные данные не исчезают |
| Ввести отрицательный бюджет / 1.001 / пустое имя | Сохранение недоступно |

Публичное учебное API может не менять цены. Проверка истории изменений и отказа
второй страницы выполняется детерминированными интеграционными тестами, без подмены
данных в пользовательской сборке.
