# Карта требований преподавателя

| Требование | Реализация |
|---|---|
| Рабочая база ДЗ №3 | CatalogScreen, DetailScreen, Navigation, Retrofit, ViewModel |
| Loading / Error+Retry / Empty / Success | CatalogModel + тесты последовательностей |
| Hilt | Injection, @HiltViewModel, @HiltWorker; зависимости вне UI |
| Room используется в работе | UI читает карточки и личные данные из БД |
| 6+ unit / 3+ integration | 20 unit, 19 integration на JVM; ещё 3 androidTest |
| 2+ нетривиальных контракта | Новый запрос при Retry, отсутствие дублей, каскады, откат частичной синхронизации |
| Полная последовательность Flow | Loading→Error→Loading→Success и Loading→Success |
| Нетривиальное поведение Flow | Debounce без лишних эмиссий, отмена устаревшего запроса |
| 3+ независимых источника | Query, category, favorites, Room products/personal, DataStore, sync |
| Объединение и преобразование | combine, debounce, distinctUntilChanged, map, collectLatest |
| Настройки / recent / личный раздел | Настройки, История, Моё, Списки, Фильтры |
| Личные данные не один boolean | Заметки/цели, Plan/PlanEntry, бюджет/количество/статус, пресеты |
| 3+ новых законченных сценария | Планирование, отслеживание цены, пресеты, подготовка офлайна |
| 2 существенных сценария | Many-to-many планы с бюджетом; личные цели с историей и фоновой актуализацией |
| Новые сущности и связи | plans ↔ entries ↔ products, personal, presets, price_points |
| DataStore только для настроек | Тема, сортировка, фон, TTL |
| Offline-first | Room источник UI, транзакционный refresh, сохранение кэша при сбоях |
| WorkManager по назначению | Уникальная периодика, TTL, сеть, backoff, явная предзагрузка |
| Тесты нового функционала | Бюджет, цели, пресеты, история цены, offline/sync/worker/UI |
| README и PR | README, RUN_AND_SUBMIT, PR_DESCRIPTION |
